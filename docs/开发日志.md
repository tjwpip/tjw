## 2026年7月15日

### 📌 今日修改概览

#### 1. 修复身份证工具文件读取路径问题
- **文件**: `tjw/core/shengfenzheng/sfz.py`
- **问题**: 使用相对路径读取 `gb2260.json` 文件导致 FileNotFoundError
- **修复**: 使用 `os.path.join(os.path.dirname(__file__), "gb2260.json")` 获取正确路径

#### 2. 修复JSON文件编码问题
- **文件**: `tjw/core/shengfenzheng/sfz.py`
- **问题**: Windows系统默认GBK编码无法读取UTF-8编码的JSON文件
- **修复**: 添加 `encoding="utf-8"` 参数

#### 3. 修复JSON数据格式解析问题
- **文件**: `tjw/core/shengfenzheng/sfz.py`
- **问题**: JSON文件为字典格式，但代码期望列表格式
- **修复**: 使用 `list(diqu_data.keys())` 和 `diqu_data.items()` 正确处理字典数据

#### 4. 身份证工具页面重构
- **文件**: `web/static/js/main.js`, `web/static/css/main.css`
- **功能**: 将四个功能模块改为标签页切换形式
- **布局**: 顶部工具栏显示图标按钮（🎯生成、🔄批量、✅验证、📍归属地）
- **默认**: 打开页面默认显示"生成单个身份证"功能

#### 5. 添加回车键提交功能
- **文件**: `web/static/js/main.js`
- **功能**: 所有输入框支持回车键提交对应功能

#### 6. 添加侧边栏展开/收缩功能
